Scoreboard

Teams answer with the letter of their choice. Press 1–9 to mark a team correct on the current question. Press it again to take the points back. Use − / + on a team for penalties or bonus points.

Tap a choice to answer. You get one try per question, and the game checks it right away. Your score and mastery report stay on this device.

Edit questions

One question per line: Round :: Topic :: Question :: Answer :: Hint :: Choices. Hint and choices are optional. Write the choices with the correct one first, separated by ;;, for example 60° ;; 45° ;; 30° ;; 120°. The game shuffles them. Round is E Easy, A Average, D Difficult or C Clincher. Lines starting with # are ignored. The Topic is used to group the mastery report. Changes stay in this browser.
